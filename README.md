What this is
- A responsive, static prototype inspired by The Economist layout.
- Placeholder images (picsum.photos) and sample copy.
- Files:
  - index.html
  - styles.css
  - script.js

How to preview locally
1. Save the files into a single folder.
2. Open index.html directly in your browser OR run a simple local server:
   - Python 3: python -m http.server 8000
   - Then open http://localhost:8000
